A simulator that does the dice rolling and maths of Warhammer 40k 10th edition for you. It uses RNG for the dice and checks against the inputted parameters to see whether the dice succeed or fail. 

Technologies used: Java 24, uses the java.util libraries

To use, download and locate the file location with cmd and run (make sure you have a jdk) and enter the data that it asks(int unless otherwise stated) and it will output the result of attacking
